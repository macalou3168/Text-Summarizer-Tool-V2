## 💡 Choosing a summarization method

The tool offers two main ways to process information:

### BART Summarization
This method functions like a human reader. It understands the context and writes a creative summary. Use this for reports, long emails, or news articles where you need a concise overview.

### TF-IDF Summarization
This method acts like a highlighter. It inspects word frequency to find the core sentences. Use this for legal documents, technical papers, or when you need to keep the original phrasing of the text.
